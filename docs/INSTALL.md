# Install

1. Quit Steam completely (also from the system tray near the clock).
2. Open your Millennium themes folder. For most people this is
   `C:\Program Files (x86)\Steam\millennium\themes`.
   (In Steam: Millennium settings -> Themes has a folder button that opens it.)
3. If an older copy of this theme is there, move it somewhere safe as a backup, then put the new `LiveSteam`
   folder in. The path must read `themes\LiveSteam\skin.json`, not `themes\LiveSteam\LiveSteam\skin.json`.
   The folder name can be anything; Millennium uses it as the theme's identity.
4. In Millennium's settings make sure JS insertion is enabled.
5. Start Steam and select the theme in Millennium's settings -> Themes (restart Steam if asked).

To update later: quit Steam, replace the same folder, start Steam.
To uninstall: select another theme in Millennium's settings, then delete the folder.
